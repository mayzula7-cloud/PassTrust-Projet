# PassTrust-Projet

MVP de PassTrust : une plateforme de confiance pour demander ou proposer de l’aide entre particuliers.

## Fichiers
- `index.html` : page d’accueil
- `supabase-client.js` : envoi des formulaires vers Supabase
- `admin.html` : dashboard admin
- `admin.js` : logique du dashboard admin
- `schema.sql` : schéma Supabase

## Déploiement
- héberger via GitHub Pages
- connecter le site à Supabase
- créer un compte admin dans `admin_users`
